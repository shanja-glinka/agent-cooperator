# Прерванные исходные попытки 1.9.1

Три оригинальных запуска большой задачи оставили регистрации активных процессов, но ни один исходный процесс с соответствующим BENCH_CELL не был обнаружен при проверке около 19:27 UTC. Потоки терминальных событий перестали обновляться между 19:16:22 и 19:16:46 UTC. Все сохранённые журналы ячеек совпали по SHA-256 с описью, составленной до переноса архива. В трёх исходных каталогах отсутствуют код завершения сеанса, время завершения, вердикт стенда, итоговый замер Git и provenance. Во всех архивных рабочих деревьях HEAD остался на исходном коммите. Точная причина остановки хостовых процессов по этим данным неизвестна.

Журналы двух сеансов Codex содержат 343 запроса на 98,2093385 стандартного кредита. Расчёт включает каждый уникальный response ID каждой роли и не прибавляет reasoning повторно. Для Claude учтены уникальные сообщения моделей из основного и дочерних транскриптов по правилам metrics.mjs, с тарифом и длительностью кэширования каждого запроса. Суммы отражают расход, подтверждённый журналами до обрыва. Официальный итоговый счёт и незаписанные ответы неизвестны. Результаты внутренних CI относятся к конкретным промежуточным деревьям. Ни одной из трёх попыток не присвоен результат скрытых приёмочных проверок или статус чистой изоляции. Новые повторные запуски имеют собственные исходы и отдельный расход.

Хеши исходных журналов, границы замеров и расход по каждой модели доступны в [машиночитаемой описи](interrupted-usage.json).

[Реестр 459 запросов](interrupted-requests.jsonl) сформирован штатным metrics.mjs на копии структуры архива. В реестре остались только категория токенов, модель, роль, порядковый номер агента и метка исходной попытки. [Независимый пересчёт](verify-interrupted-ledger.py) воспроизводит [целочисленные суммы токенов и стоимость](interrupted-request-totals.json) по реестру без доступа к приватным данным. Из 103 запросов Haiku 24 перешли на тариф для длинного контекста.
