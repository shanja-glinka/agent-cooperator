# Сравнение маршрутизации Codex

Исходный кит cf61bb5, кандидат e444402. Гипотеза относится к выбору маршрута до чтения большого навыка. Изменилась только точка входа Codex в управляющий навык. Для ограниченной задачи с проверяемым результатом кандидат предлагает работать в основной сессии. При самостоятельных крупных блоках или обязательной оркестрации сохраняется штатный процесс с исполнителем и ревью.

Сетка: четыре замороженных задания, два повтора, без кита / 1.8.1 / кандидат. Codex CLI 0.172.0, только GPT-6.2 Sol high. Профиль Economy. Контроль Claude Code 2.1.332, Opus medium и штатный Hybrid. Одинаковые базы, задания, скрытые тесты, хост и замороженные зависимости для всех вариантов. Ни один диагностический запуск не входит в эту сетку.

Основной критерий: выполненный контракт, проверенный независимым скриптом задачи; для big обязательны четыре скрытых проверки. Проверять также выход процесса, наличие ответов модели и доставленного коммита. Ошибки входа, лимита или инфраструктуры учитывать отдельно. Для сопоставления брать чистые ячейки. Различия в стенде и пропущенные проверки сообщать.

Гипотеза о маршруте предсказывает меньше чтений кита и ненужных назначений на ограниченных задачах. Сравнивать число запросов, входных/выходных токенов и время при том же достигнутом результате. Цена для 6.2 рассчитана по допущению стенда, деньги со счета оценивать отдельно. Два повтора дают диапазоны; пересечения не устанавливают равенство. Проверить также успешность big и результаты обоих вариантов Claude; не переносить вывод о коротких задачах на долгие пайплайны. Если кандидат снижает качество или эффект не установлен, не переводить его в основной кит.

Уточнение до запуска: основная цель пользователя — снизить расход лимита при сохранении результата. Считать все запросы основной и дочерних моделей. Квота в журналах округлена до процента общего окна аккаунта; при параллельных запусках приписывать её отдельному варианту нельзя.
